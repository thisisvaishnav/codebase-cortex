# Prizes

**Total Prize Pool: $10,000**

## Prize Tracks

### 🏆 1. Grand Prize — Double-O Track
**Prize:** NVIDIA DGX Spark (~$5,000 value)
**Awarded for:** Best Use of TrueForge

What judges look for:
- Real MCP tools connected and used
- Sandboxed code execution
- Human approvals implemented
- Sub-agents used for parallel/delegated work
- Persistent sessions
- Other TrueForge capabilities used effectively

---

### 🤖 2. Q Branch Track
**Prize:** Mac Mini
**Awarded for:** Best Code Quality

Requirements:
- **Using Qodo is required** to win this track
- Run pull requests through Qodo, address findings
- Repository must be something another developer could clone, understand, and extend
- Project should look like real software, not just a hackathon demo

---

### 🌐 3. Universal Exports
**Prize:** Job interviews at TrueFoundry
**Awarded for:** Top Projects (judged holistically)

- Nothing to apply for — no separate track to enter
- Judges pass top team names to TrueFoundry
- Winning another track is neither a condition nor a guarantee

---

### ✍️ 4. Field Report
**Prize:** Keychron Keyboard
**Awarded for:** Best Blog Post

What the post should cover:
- The problem you chose
- How you built the agent
- How TrueForge helped
- What broke along the way
- What you learned

How to enter: Publish anywhere, add the link to your submission.

---

### ⭐ 5. Calling Card
**Prize:** Logitech MX Master 3
**How to enter:** Star the [TrueForge GitHub repository](https://github.com/truefoundry/trueforge) and you're entered into the draw.

> No project required.

---

### 📡 6. Radio Traffic
**Prize:** Swag for the Top 10 Social Posts
**How to enter:**
- Post a clip of your agent working
- Share something surprising
- Talk about a bug you encountered
- Show progress you're making

Tag **WeMakeDevs** and **TrueFoundry** in your posts.
